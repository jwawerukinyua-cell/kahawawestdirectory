# Kahawa West Directory Public Assets
Place your three images in this `/public` directory:

1. `hero.jpg` - The main banner background image (Kahawa West roundabout & landscape).
2. `logo.png` - The brand emblem or logo icon.
3. `about.jpg` - The community or landmark photo shown in the About modal / directory showcase.

Any file placed in `/public/` is automatically accessible at `/hero.jpg`, `/logo.png`, and `/about.jpg` in the application.
